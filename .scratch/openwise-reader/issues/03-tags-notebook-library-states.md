# 03: Tags, Notebook, Library States (Inbox / Later / Archive)

**What to build:** Every saved document has a Notebook panel showing highlights, notes, headings, and tags. Documents live in Inbox / Later / Archive with one-tap transitions. Tags can be added to documents and highlights, with rename and merge support.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Document Notebook panel lists highlights, notes, headings, and tags
- [ ] Clicking a highlight in the notebook jumps to its position in the document
- [ ] Documents have a state field (Inbox / Later / Archive)
- [ ] +Add places new documents in Inbox by default
- [ ] One-tap Inbox → Later → Archive works from the document and the list
- [ ] Tags can be added to documents and highlights
- [ ] Typing a tag suggests existing tags first; new tags are creatable inline
- [ ] Tags can be renamed (with merge-by-default behavior) and merged manually
- [ ] Tags are searchable from the global search box
- [ ] Documents in Later show a "Continue reading" affordance on Home

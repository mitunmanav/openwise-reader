# 16: AI (provider abstraction, document AI, chat with highlights, custom prompts)

**What to build:** A pluggable AI provider abstraction supporting Disabled / Ollama-compatible / OpenAI-compatible / custom endpoint. Document AI actions (Summarize, Explain, Simplify, Define, Translate, Expand, Extract key ideas, Extract action items, Generate questions, Generate flashcard, Ask document). Chat with highlights with citation. Custom reusable prompts with variable substitution. Auto-summary / auto-tag opt-in.

**Blocked by:** 02, 03, 15

**Status:** ready-for-agent

- [ ] AI disabled by default; provider abstraction supports at least three backends (Ollama-compatible, OpenAI-compatible, custom endpoint)
- [ ] Each AI action is opt-in per feature (no implicit AI usage)
- [ ] Document AI actions work (Summarize, Explain, Simplify, Define, Translate, Expand, Extract key ideas, Extract action items, Generate questions, Generate flashcard, Ask document)
- [ ] Document chat scopes to the current document unless the user explicitly expands scope
- [ ] Document chat answers are grounded in source passages with clickable citations
- [ ] Chat with highlights draws only from the user's library and exposes the highlights used
- [ ] Chat with highlights never pretends something came from the library when it did not
- [ ] Custom prompt creation with variable substitution (title, author, content, selection, highlights, notes, tags, user query)
- [ ] Auto-summary and auto-tag are off by default and individually togglable
- [ ] AI settings page shows which data leaves the device per feature
- [ ] AI failures never block reading or annotation (graceful degradation)

# 18: Desktop Shell (Tauri)

**What to build:** A Tauri desktop app for Windows, macOS, and Linux that wraps the same web build with platform-appropriate affordances: drag-and-drop import, full keyboard navigation, command palette, local-file access, and global "save to OpenWise" shortcut where the OS permits.

**Blocked by:** 02, 10

**Status:** ready-for-agent

- [ ] Tauri desktop app packages for Windows, macOS, Linux
- [ ] App icon, name, and metadata are correct for each platform
- [ ] Drag-and-drop import of files (PDF, EPUB, MD, images) works
- [ ] Full keyboard navigation throughout the app
- [ ] Command palette (Ctrl/Cmd+K) opens and runs all listed commands
- [ ] Local-file access for opening files outside the library (read-only)
- [ ] Auto-update mechanism works on each platform
- [ ] App data directory follows OS conventions (no scattered files)
- [ ] Native menu bar with platform-appropriate items

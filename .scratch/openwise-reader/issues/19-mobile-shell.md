# 19: Mobile Shell (Expo)

**What to build:** An Expo mobile app for iOS and Android that wraps the same web build with platform-appropriate affordances: bottom navigation, prominent Add, OS share sheet, camera OCR for physical books, full offline reading, highlighting, notes, review, search.

**Blocked by:** 02, 10

**Status:** ready-for-agent

- [ ] Expo mobile app packages for iOS and Android
- [ ] Bottom navigation (Home, Library, Review, Search) with prominent Add action
- [ ] Reading consumes nearly the full screen with safe-area handling
- [ ] OS share sheet integration (URL, file, selected text)
- [ ] Camera-based OCR for physical books (launches camera → OCR → highlight flow)
- [ ] Full offline reading / highlighting / notes / review / search
- [ ] Sync indicator shows online / syncing / offline state
- [ ] Native gesture handling for highlight creation (long-press, drag handles)
- [ ] TTS controls accessible from the reader
- [ ] App icon, name, and metadata correct for both platforms
